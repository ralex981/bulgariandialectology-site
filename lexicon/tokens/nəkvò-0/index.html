nəkvò

Meaning:
such
Gender:
n
Deictic:
dist
Lexeme:
онакъв
Other:
adj
Number:
sg
Linguistic trait:
eli unstr vow

  • Mogilica 3: 64 - tegàvə petmès ud nègə iskàrvəhme zàhərnu nəkvò beše
