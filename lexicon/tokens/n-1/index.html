n

Particle:
neg
Lexeme:
не
Linguistic trait:
eli unstr vow

Lines where n appears

  • Arčar 1: 53 - ednà fadròmka go isìpa tàmo onò n bèše mnògo ama stignà
  • Dolna Sekirna 3: 47 - da n gùbimo sèki dɤ̀n ìde se na ràbotu
  • Drjanovec 2: 50 - či tò tè tɤ n sì li t’ì tì
  • Golica 3: 43 - dèt sne vəršɛ̀li nìšto n znàjat ud nib'èto
  • Golica 3: 150 - às də n cɛ̀m mɑ̀lka mà mə
  • Golica 5: 99 - s vərtul’èt dušlì ud rusìjə i tìj ku n b’àha
  • Huhla 2: 30 - ku n mù ujdìsə əpərtəm'èntə də si ìde nə kɤ̀štə
  • Huhla 4: 36 - zəkàrəhə i nə fròntə v'èke n gì dukàrəhə ustànəhə si tàm
  • Iskrica 3: 84 - də də n sùčət vèči pòčvəme də duìm màjkite im
  • Kruševo 1: 61 - lù si sə uvìkvə nəlì jà n vì kàzvəm də sə pràv’ə
  • Mogilica 3: 11 - ə màlko màlko tùk tàm n počtì nèmə
